# Modern Chanakya

**Modern Chanakya** is a high-fidelity, interactive strategic command center designed for leaders, founders, and consultants. It brings together over 100+ precision-crafted strategic frameworks onto a modern digital canvas.

## 🚀 Experience Strategy in High Definition

Unlike static templates, Modern Chanakya provides an interactive workspace where strategy isn't just documented—it's designed.

### Key Features

- **100+ Strategic Frameworks**: From foundational models (SWOT, 4Ps, Porter's Five Forces) to advanced innovation tools (Wardley Maps, Blue Ocean, Real Options).
- **Interactive Canvas**: Drag, zoom, and pan across your strategic models.
- **Dynamic Simulation**: Visual feedback systems for various models (e.g., Marketing Mix impact simulation).
- **Sticky Note Workspace**: Capture thoughts and data points directly onto the frameworks.
- **Mobile Responsive**: Fully optimized for tablets and mobile devices.
- **Modern UI/UX**: Built with React, Tailwind CSS, and Framer Motion for a fluid, professional experience.

## 🛠 Tech Stack

- **Frontend**: React 18+ (Framer Motion, Lucide Icons)
- **Styling**: Tailwind CSS (Mobile-first, Responsive)
- **State Management**: React Hooks (useState, useEffect, useMemo)
- **Build System**: Vite

## 📂 Framework Categories

Modern Chanakya organizes wisdom into actionable buckets:
- **Strategy & Innovation**
- **Marketing & Sales**
- **Problem Solving & Decision Making**
- **Leadership & Teams**
- **Operations & Supply Chain**
- **Finance & Risk**
- **Change & Communication**

## 📖 How to Use

1. **Select a Framework**: Choose from the extensive sidebar or the hero dashboard.
2. **Interact**: Use the Canvas tools (Pointer/Pan) to navigate.
3. **Capture**: Add sticky notes to specific sections of any framework.
4. **Iterate**: Refine your strategy with visual clarity.
